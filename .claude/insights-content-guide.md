# OHI Tech Insights — 블로그 콘텐츠 작성 가이드 (SEO + GEO)

> **모든 Insights 아티클 작성 시 이 가이드를 반드시 따를 것.**
> 위반 시 네이버 노출 불리, AI 브리핑 미인용으로 유입 손실 발생.

---

## 1. 핵심 철학

**"OHI Tech가 직접 공급·납품·테스트한 경험"** 을 중심으로 쓴다.

- ❌ 백과사전형: "레이저란 빛을 증폭시키는 장치입니다."
- ✅ 경험형: "OHI Tech가 SiC 웨이퍼 다이싱에 워터젯 레이저를 적용한 결과, HAZ가 0이고 커프 폭이 0.02mm였습니다."

AI 브리핑은 일반 정보를 대체한다. 블로그가 살아남는 유일한 방법은 **AI가 가져올 수 없는 1차 경험과 비교 데이터**다.

---

## 2. Naver SEO 규칙 (2026 최신)

### 2-1. 알고리즘 변화 핵심
- 네이버 AI 랭킹 모델: 키워드 반복 → **신뢰도·전문성·경험** 중심으로 전환
- 체류 시간이 랭킹에 직접 반영 (스크롤 깊이, 머문 시간)
- 연관검색어 종료(2026.4.30) → AI 브리핑 + 관련 질문이 대체
- 정보 나열형 글은 공공기관/공식 사이트에 밀림

### 2-2. 제목 규칙
```
형식: [핵심 키워드] + [수치/구체 결과] + [독자 질문 해소]
길이: 35자 이내 (모바일 잘림 방지)

✅ 좋은 예:
- "SiC 웨이퍼 다이싱, 워터젯 레이저가 CO₂보다 나은 3가지 이유"
- "ESC 정전척 선택 기준 — Coulombic vs Johnsen-Rahbek 방식 비교"
- "드라이 진공 펌프 수명 2배 늘리는 유지보수 체크리스트"

❌ 나쁜 예:
- "산업용 레이저 장비 완벽 가이드" (너무 일반적)
- "ESC란 무엇인가" (AI 브리핑이 대체)
```

### 2-3. 구조 규칙
- **결론 먼저**: 서론 2~3문장 안에 "이 글에서 알 수 있는 것" 명시
- **소제목**: H2 최소 4개 이상, 질문형 또는 핵심 키워드 포함
- **문단 길이**: 3문장 이내. 모바일에서 한 문단이 화면을 넘어가면 안 됨
- **목록 활용**: 3개 이상 항목은 반드시 bullet 또는 번호 목록
- **표**: 비교 내용은 반드시 표로 정리 (AI 브리핑 인용 가능성 상승)
- **글 길이**: 1,500자 이상 (체류 시간 확보)

### 2-4. 키워드 배치
```
- 제목: 핵심 키워드 1개
- 첫 문단: 핵심 키워드 자연스럽게 1회
- 소제목: 관련 키워드 분산 배치
- 본문: 키워드 밀도 1~2% (억지 반복 금지)
- 마지막 문단: 핵심 키워드 1회 + CTA
```

### 2-5. 태그 (네이버 블로그용)
- 태그 10~15개
- 핵심 키워드 + 제품명 + 산업 키워드 + 문제 키워드 조합
- 예: `#워터젯레이저 #SiC웨이퍼다이싱 #레이저가공 #반도체레이저 #HAZ없는레이저`

## 3. GEO 규칙 (Generative Engine Optimization)

AI 브리핑, ChatGPT, Perplexity 등이 이 글을 인용하도록 최적화한다.

### 3-1. AI가 인용하는 문서의 조건
1. **출처가 명확한 수치**: "OHI Tech 납품 사례 기준, 커프 폭 0.02mm"
2. **비교 구조**: "A방식 vs B방식" 테이블
3. **단계별 설명**: 순서가 있는 프로세스 (1→2→3)
4. **FAQ 구조**: "Q: 왜 워터젯 레이저를 쓰나요? A: ..."
5. **구체적 수치와 단위**: 모호한 "빠릅니다" 대신 "처리 속도 15mm/s"

### 3-2. AI 브리핑 인용을 높이는 문단 구조
```markdown
## [소제목 — 질문형 권장]

[핵심 답변을 첫 문장에 배치 — AI가 스니펫으로 가져감]

[보조 설명 1~2문장]

[수치 또는 사례]
```

### 3-3. 구조화 마크업 활용
- FAQ 섹션은 글 마지막에 항상 포함 (AI 인용 + 네이버 지식iN 연결 가능)
- 표는 헤더 행 명확히 (AI가 표 데이터를 직접 인용)
- 단계별 프로세스는 번호 목록으로 (AI가 스텝으로 인용)

## 4. 글쓰기 스타일 — 네이버 블로그 포맷

### 4-1. 어조
- **~합니다체** 사용 (격식 + 친근함)
- 독자에게 직접 말 걸기: "~하셨나요?", "~이실 텐데요"
- 1인칭 OHI Tech 관점: "저희가 직접 공급한 제품에서...", "OHI Tech 엔지니어링팀이 확인한..."

### 4-2. 도입부 (반드시 이 구조)
```
1문장: 독자의 고민/문제 제시 ("SiC 웨이퍼 가공 중 칩핑이 발생한다면...")
2문장: 이 글이 줄 것 ("이 글에서는 OHI Tech가 실제 납품 현장에서 확인한 해결책을 공유합니다.")
3문장 (선택): 신뢰 근거 ("10년간 반도체 부품 공급 경험을 바탕으로...")
```

### 4-3. 본문
- 소제목 사이 문단: 최대 5~6줄
- 이미지 플레이스홀더 위치 명시: `[이미지: 제품명_설명]`
- 강조는 **볼드** 사용 (밑줄, 색상 사용 금지)
- 숫자가 있으면 단위 꼭 붙이기 (mm, bar, nm, ℃)

### 4-4. 마무리 (CTA)
```
형식:
"[주제]에 대한 추가 문의나 샘플 테스트가 필요하시면 OHI Tech에 문의해 주세요.
실제 소재를 가져오시면 가공 가능 여부를 사전 검증해 드립니다."

연락처: contact@ohitech.co.kr
```

## 5. OHI Tech 전용 콘텐츠 규칙

### 5-1. 반드시 포함할 것
- [ ] OHI Tech가 공급/취급하는 제품임을 명시
- [ ] 실제 납품/적용 사례 또는 테스트 결과 (수치 포함)
- [ ] 경쟁 방식 대비 OHI Tech 제품의 구체적 차이
- [ ] 고객이 연락할 수 있는 CTA

### 5-2. 절대 포함하지 말 것
- 타사 경쟁사 이름 직접 언급 (제품 카테고리로만 비교)
- 확인되지 않은 수치나 스펙 (반드시 검증된 데이터만)
- "최고", "유일한", "압도적" 같은 근거 없는 최상급 표현

### 5-3. 언어별 처리
- **ko**: 전체 작성 (네이버 SEO 최적화)
- **en**: ko 내용 기반으로 GEO 최적화 (AI 인용 구조 강화, FAQ 필수 포함)
- **zh**: ko 내용 직역 + 중국 시장 키워드 추가
